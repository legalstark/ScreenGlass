# 显示器列表热插拔刷新修复

2026-11-10，本机 Windows 已识别 CA27D0（BOEAA00，2560×1440，扩展桌面），运行中的主面板仍只显示 DISPLAY1。

原因：主面板在 `Loaded` 回调中调用 `DisplayPanel.Attach`，子控件此时已完成首次加载。原实现只在后续 `Loaded` 事件订阅 `ControlsChanged`，因此后台重建显示器列表后，已打开的面板没有刷新。修复为 Attach 时立即订阅，保留卸载时取消订阅及重新加载时重新订阅。

仅验证本次涉及的显示器列表与每屏控件刷新：

- 修复前程序集复现失败：显示器移除后，已打开的列表仍保留旧条目。
- 修复后程序集通过：当前 CA27D0 设备接口可检测；现有面板同步移除和加入屏幕；屏幕重排后保留所选外屏；每屏调暗数值随控制器更新。
- Release 编译通过，0 警告、0 错误。

列表变更测试直接调用实际的遮罩重建方法，模拟设备加入、移除和重排，未实际拔插接线。测试使用独立设置文件，不修改用户偏好。

本机检测与验证输出：`dist/display-refresh-verification/displays.json`、`checks.txt`。未回归未修改的柔光算法、音效、皮肤和平台玻璃效果。
