ScreenGlass 0.8.0 · 珠宝太阳镜 / Pocket Edition

运行
解压后双击 ScreenGlass.exe。无需安装 .NET、无需管理员权限。
适配目标为 Windows 10 22H2（19045）、Windows 10 企业版 21H2 / LTSC 2021（19044），以及 Windows 11 22H2（22621）及更新版本，均为 x64。Win10 的视觉效果与流畅度待目标机器实测验收。磨砂背景遵循 Windows 透明效果设置。
启动默认暂停柔光，点击开关或镜片开启。

快捷操作
单击托盘图标：打开快捷框；双击：打开完整工作台。
点击太阳镜：开启或暂停柔光。
在镜片或强度滑块上滚轮：每次调整 1%；Shift + 滚轮：每次调整 5%。
日常 28%、阅读 38%、深夜 50%（微暖），调节强度不会自动开启柔光。
智能跟随：按原来的连续亮度曲线及时响应页面明暗，滑块控制最大强度。白底阅读时的小幅波动保持当前强度；明显变化在下一次采样时响应，无额外确认等待。
低敏模式：持续明亮才开启固定强度，配合智能跟随使用。
默认 Ctrl+Alt+S 开关柔光；Ctrl+Alt+A 开关智能跟随。偏好设置的“快捷操作”中可点击输入框后按自定义组合键，自动保存并立即生效；可恢复默认，重复或被占用时会明确提示。
快捷框喇叭点击静音、右键试听；偏好页也可开关音效或点击“试听音效”。
试听不改变静音设置，不调整系统音量；无输出设备或播放失败时会明确提示。
快捷框底部四色圆点可切换翡翠、蓝宝石、玫瑰碧玺、香槟琥珀皮肤，也可在偏好页选择。
快捷框标题显示当前版本。仍显示旧界面时请从旧版托盘菜单彻底退出再打开。
点击外部或按 Esc 收起快捷框；关闭主窗口仍在托盘运行。
要彻底退出，请在托盘右键菜单选择“退出 ScreenGlass”。

设置与隐私
设置保存于 %LOCALAPPDATA%\ScreenGlass\settings.json。
屏幕采样仅在本机内存中处理，不保存截图或上传屏幕内容。
点击「检查更新…」时，应用向 GitHub 查询最新正式版本，请求包含应用名称和版本号。
这是软件遮罩，不调节显示器硬件背光，不提供医疗效果承诺。

升级
在托盘右键菜单选择「检查更新…」。发现更新时，可打开 GitHub 发布页下载。
先从托盘退出旧程序，再运行新版本。不必复制旧安装目录的 settings.json。
删除程序即卸载；如需同时删除偏好，可自行删除上述设置目录。

0.7 每屏调暗：
在完整工作台或托盘快捷框选择显示器，单独调整固定调暗（0%–90%）和此屏开关。
关闭“叠加柔光”可单独使用调暗；暗色页面也保持。微暖色调可独立开启。
总开关必须开启才生效；启动始终暂停。界面皮肤不改变遮罩颜色。
软件遮罩不控制 LCD 背光，纯黑像素无法再变暗。本版不包含硬件亮度控制。
每屏设置按设备接口身份保存。更换接线端口可能产生新的身份；镜像屏共享同一桌面区域。
